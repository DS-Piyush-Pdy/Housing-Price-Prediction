# 🏠 Housing Price Prediction

A Machine Learning project that predicts median house values
using the California Housing dataset.

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Joblib

## ML Pipeline

1. Load housing dataset
2. Create income categories
3. Perform stratified train-test split
4. Separate features and target
5. Handle missing values
6. Standardize numerical features
7. One-hot encode categorical features
8. Train Random Forest Regressor
9. Save trained model and preprocessing pipeline
10. Generate predictions on new input data
